Day 02 – Java Variables, Data Types and Output Statements

Workshop: FullStack Experts Academy

1. Variables in Java

A variable is a named memory location used to store data.

Example:

int age = 20;
String name = "Hero";

2. Data Types in Java

Data types specify the type of data stored in a variable.

- int – Stores integer values.
- String – Stores text.
- char – Stores a single character.
- boolean – Stores true or false.
- double – Stores decimal values.
- long – Stores large integer values.

Example:

int age = 20;
String name = "Hero";
char gender = 'M';
boolean isEmployee = false;
double percentage = 85.5;
long mobile = 9876543210L;

3. Variable Declaration and Initialization

Declaration: Creating a variable.

int age;

Initialization: Assigning a value to a variable.

age = 20;

Declaration and Initialization together:

int age = 20;

4. Output Statement

In Java, System.out.println() is used to display output on the console.

Example:

System.out.println("Hello World");

Output:

Hello World

5. String Concatenation

String concatenation means joining two or more values using the + operator.

Example:

String name = "Hero";
int age = 20;

System.out.println("My Name is: " + name);
System.out.println("My Age is: " + age);

Output:

My Name is: Hero
My Age is: 20

6. For Loop

A for loop is used to execute a block of code repeatedly.

Syntax:

for (initialization; condition; increment) {
    // statements
}

Example:

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Output:

1
2
3
4
5

7. Math.pow() Method

The Math.pow() method is used to calculate the power of a number.

Example:

System.out.println(Math.pow(2, 3));

Output:

8.0

8. If-Else Statement

The if-else statement is used to make decisions based on conditions.

Example:

boolean isEmployee = false;

if (isEmployee) {
    System.out.println("Employment is done");
} else {
    System.out.println("Employment is not done");
}

Output:

Employment is not done

9. Key Learnings

- Learned variables and data types in Java.
- Understood variable declaration and initialization.
- Practised String concatenation using the + operator.
- Learned for loops and Math.pow().
- Understood if-else statements.
- Practised displaying output using System.out.println().
